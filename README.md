## 这是什么

《三变·六反》体系的地缘风险跟踪与推演前端：以「已核实的最低确证数」记录战争伤亡（生命之祭），
再以战略资源、资源民族主义、AI 军事化、七维风险因子模型与情景沙盘，推演地缘风险的结构与路径。

**它不做什么**：不预测、不荐股、不替读者下结论。它把材料摊开，判断留给你。

## 两类内容 · 不可混读

| | 是什么 | 怎么看 |
